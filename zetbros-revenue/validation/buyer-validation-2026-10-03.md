## Prioritized shortlist

### 1) Best current fit — MCP Server Build: Third-Party API Integration for Claude AI

[Open the Upwork listing](https://www.upwork.com/freelance-jobs/apply/MCP-Server-Build-Third-Party-API-Integration-for-Claude_~022101805896836781022/)

- **Availability snapshot:** On Oct 3 the direct job detail remained public and showed the full description, without a “job is no longer available” notice. That is not proof the client is still accepting applicants. Upwork’s page title metadata says posted Sep 20, while the page body says “posted last week”; retain the discrepancy and recheck before any action. The direct detail shows 50+ proposals, 1 interview, and client last viewed last week. A separate Upwork search snapshot showed “yesterday” for last view, so the activity timestamp appears to lag or vary between surfaces.
- **Buyer-stated terms:** $750 fixed price; the description says Phase 1 budget $500–$1,000, 6–10 hours, delivery within five business days, and 50% at start / 50% after successful delivery and testing. Those are advertised terms, not a signed contract or payment.
- **Scope:** One third-party REST API into a lightweight MCP server for Claude; key-based auth in request headers; specified query endpoints; structured JSON; a Claude query test; no frontend, storage, or Claude-side logic. Hosting on Railway/Render or similar is preferred. The technical brief follows NDA signing.
- **Why it fits:** One API, read/query path, short stated timeline, and a listed $750 amount are relevant signals for a narrow integration service. A sensible bounded proposal would restrict v1 to named read-only endpoints, server-side secrets, validated structured output, basic error handling, a test, and a concise deployment README. No write scope until separately specified and approved.
- **Competition / gaps:** 50+ proposals is a tough funnel. Unknown API, data sensitivity, endpoint count, rate limits, hosting requirement, acceptance test, support expectation, NDA identity/terms, and whether the job remains open. The scope can exceed 6–10 hours depending on API quality and auth edge cases.
- **Qualification next step if pursuing:** First confirm the job is still open and the NDA is acceptable before receiving the brief. Ask for the API name/docs, exact endpoint list, sample response, read-only confirmation, hosting/ownership expectations, test acceptance criteria, and any support/warranty expectation. Don’t promise the 6–10 hour estimate until the API and endpoint list are known.
- **Assessment:** Top lead; good service fit, low odds because of competition and unresolved scope.

### 2) Conditional high-fit — Applied AI Adoption & Secure Workflow Pilot for U.S. Law Firm

[Open the Upwork listing](https://www.upwork.com/freelance-jobs/apply/Applied-Adoption-Secure-Workflow-Pilot-for-Law-Firm_~022099676530332782727/)

- **Availability snapshot:** Direct page remains public on Oct 3 and shows the description. It says posted two weeks ago, 50+ proposals, client last viewed last week, 1 hire, and 1 interview. This may still be live, but a hire has already occurred and availability is uncertain.
- **Buyer-stated terms:** Hourly $30–$60; under 30 hours/week; 1–3 months. This is a rate range, not a project-total budget or earned revenue.
- **Scope:** Paid discovery plus a pilot to choose one or two low-risk workflows; process map and solution design; optional limited prototype; lightweight evaluation, citations/source traceability as applicable, failure modes, access controls, human approval, and handoff. The listing expressly says no legal advice, no unsupervised confidential-client-data use, and that the initial pilot uses sanitized/synthetic/approved non-sensitive material pending separate security review.
- **Why it fits:** The buyer explicitly values workflow mapping, security, approval, evaluation and documentation, rather than a generic chatbot. A single read-only internal document or reporting workflow could map to Zetbros’ audit + secure sprint ladder.
- **Competition / gaps:** 50+ proposals, one hire and one interview reduce near-term odds. The job asks for production/near-production evidence, sensitive-data/security experience, and 3–4 business hours of U.S. Mountain Time overlap. Confirm those fit. Keep the initial work within the stated synthetic/sanitized-data boundary; no live legal client data or legal-advice use without a separate access/security decision.
- **Qualification next step if pursuing:** Verify it is still considering applicants and whether there is a distinct second workstream despite the hire. Clarify which single repeated workflow the pilot should test, what success metric matters, who supplies approved synthetic inputs, what tools are in scope, and whether the paid first milestone is discovery only or includes a prototype.
- **Assessment:** Strong alignment with the security-led service; pursue only if the experience and availability requirements are true and the client confirms a live opening.
